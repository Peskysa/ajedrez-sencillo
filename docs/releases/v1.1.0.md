# Un tablero en compañía, en más pantallas

El mismo juego, ahora con distribución para Windows, Linux, web y Android, documentación e identidad visual.

## Descargas

- Windows x64: instalador EXE, Windows 10 o posterior.
- Linux x64: AppImage y DEB.
- Android 8 o posterior: APK **preliminar** firmado con clave de depuración.
- Web portátil: descomprimir ZIP y abrir index.html.
- [Web instalable](https://peskysa.github.io/ajedrez-sencillo/).

Escritorio sin firma comercial. La firma del APK preliminar puede variar entre compilaciones y requerir desinstalar la anterior; no es una distribución de Google Play. PWA recomendada para uso habitual en Android.

Verifica descargas con SHA256SUMS.txt. [Instalación](https://github.com/Peskysa/ajedrez-sencillo/blob/main/docs/INSTALACION.md).

Pruebas de motor y distribución web, capturas reales en navegador y simulación móvil. Compilar un paquete no equivale a probarlo en dispositivos físicos de todas las plataformas.

Para dos personas en el mismo dispositivo. Sin IA, juego en red ni guardado de partidas. Licencia MIT.
