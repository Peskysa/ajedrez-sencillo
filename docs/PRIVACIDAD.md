# Privacidad

Sin cuentas, anuncios, analítica, telemetría propia ni servidores de partidas. Las jugadas viven en memoria y no se guardan.

**Web:** GitHub Pages sirve los archivos y puede registrar datos técnicos conforme a su [política de privacidad](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). La caché del navegador guarda archivos para uso sin conexión, no partidas. Puedes borrarla desde los ajustes. Los badges del README utilizan GitHub y Shields.io, pero no forman parte del juego.

**Escritorio:** el paquete incluye el juego, sin servicio de actualización automática. Electron puede crear cachés y archivos técnicos en el perfil de aplicaciones del sistema.

**Android:** no declara permisos de Internet, almacenamiento, cámara o micrófono ni expone un puente JavaScript al dispositivo. Android y WebView mantienen sus propios archivos técnicos y políticas.
