# Terceros

El código original, SVG, iconos y capturas del proyecto se distribuyen bajo [MIT](../LICENSE). La web no carga bibliotecas ni fuentes externas: el aspecto de los glifos Unicode depende de las fuentes del sistema.

| Herramienta | Uso | Licencia principal |
| --- | --- | --- |
| [Electron](https://github.com/electron/electron) | Escritorio | MIT; Chromium y otros componentes con avisos propios |
| [electron-builder](https://github.com/electron-userland/electron-builder) | Instaladores | MIT |
| [Playwright](https://github.com/microsoft/playwright) | Capturas | Apache-2.0 |
| [sharp](https://github.com/lovell/sharp) | Iconos | Apache-2.0; libvips tiene su propia licencia |
| [Android Gradle Plugin](https://developer.android.com/build) | APK | Apache-2.0 |

Los paquetes de escritorio conservan los avisos de Electron. La licencia MIT del proyecto no sustituye licencias ajenas. `package-lock.json` fija las herramientas y sus dependencias transitivas.
