# Contribuir

Consulta las incidencias existentes. Para un error indica plataforma, versión, pasos y resultado esperado; en errores de reglas incluye jugadas o posición.

Lee [Desarrollo](docs/DESARROLLO.md), ejecuta las pruebas y mantén el motor independiente de la interfaz. Añade pruebas cuando cambies reglas o comportamientos con riesgo de regresión. Discute primero cambios que introduzcan cuentas o servicios remotos.

La pull request debe explicar problema, solución y comprobaciones. Las aportaciones usan MIT. No incluyas tokens, claves o datos personales.
