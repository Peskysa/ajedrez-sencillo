# Seguridad

Se atiende la última versión publicada, sin garantía de plazo.

Para problemas sensibles, usa **Report a vulnerability** en Security si está habilitado. Si no lo está, abre una incidencia con descripción general y solicita un canal privado antes de compartir detalles. No publiques secretos ni instrucciones de explotación.

Errores de reglas e interfaz usan las plantillas habituales. No hacen falta credenciales para jugar. Las claves de firma deben mantenerse fuera de Git. Consulta las limitaciones de firma en las notas de distribución.
